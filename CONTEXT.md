# Radar de Estágio

Este contexto descreve a linguagem do produto que seleciona oportunidades de estágio e as
entrega a estudantes pelo Telegram.

## Language

**Recomendação**:
Uma vaga selecionada e ranqueada para um perfil, acompanhada da nota e de sua explicação.
_Evitar_: Match, sugestão

**Recomendação entregue**:
Uma recomendação cujo envio foi aceito pelo Telegram.
_Evitar_: Vaga recebida, valor entregue

**Ativação operacional**:
A primeira recomendação entregue a um perfil. Confirma que o fluxo técnico funcionou, mas não
que o estudante percebeu valor.
_Evitar_: Ativação, primeira entrega relevante

**Ativação de produto**:
A primeira abertura de uma vaga recomendada pelo estudante. É o sinal inicial observável de que
a recomendação despertou interesse, sem comprovar ainda sua utilidade.
_Evitar_: Ativação, entrega

**Vaga útil**:
Uma recomendação que recebe feedback positivo explícito ou leva ao início de uma candidatura.
Uma abertura isolada não basta para classificá-la como útil.
_Evitar_: Vaga aberta, vaga entregue

**Candidatura atribuída**:
Uma candidatura iniciada a partir de uma recomendação do Radar.
_Evitar_: Candidatura, conversão

**Tempo até a primeira entrega**:
O intervalo entre a criação do perfil e a ativação operacional.
_Evitar_: TTV

**Tempo até o valor**:
O intervalo entre a criação do perfil e a ativação de produto.
_Evitar_: Tempo até a entrega
